# Предобуславливание для шестиугольных диэлектрических призм

Для BiCGStab в ADDA здесь реализованы два решения. Регрессия предсказывает, окупится ли построение спектрального предобуславливателя NPW. Если да, небольшой перцептрон выбирает один из девяти наборов параметров ядра. Затем ADDA применяет выбранный линейный предобуславливатель на протяжении решения. При прогнозе замедления ADDA сразу запускает обычный BiCGStab.

Вход перцептрона описывает заполнение частицей 64 ячеек, относительную высоту, размер сетки и действительную часть показателя преломления. Сеть выбирает окно, затухание и поправки к коэффициенту связи и окну. Предобуславливатель вычисляется из аналитического оператора ADDA. Веса встроены в решатель. Для запуска собранной программы Python не требуется. [Веса модели](weights/best.pt) · [Коэффициенты решения о сборке](weights/gate.json)

### Результаты

В основной проверке использованы 12 сочетаний двух отношений высоты к поперечному размеру (0,65 и 1,1), двух сеток (20 и 22) и трёх показателей преломления (2,15, 3,0 и 3,2). Показатель вещественный, число диполей на длину волны равно 30. Время включает запуск последовательного процесса, подготовку ядра, решение для обеих поляризаций и запись полей. Для каждой задачи взята медиана трёх повторов, затем эти медианы сложены.

| Вариант | Суммарное время, с |
|---|---:|
| Исходная ADDA, обычный BiCGStab | 39,66 |
| Сборка эксперимента, обычный BiCGStab | 39,26 |
| Аналитический NPW, окно Ханна, затухание 0,05 | 40,46 |
| Лучшая постоянная настройка по обучающей выборке | 12,37 |
| Та же постоянная настройка с обученным решением о сборке | **11,75** |
| Выбор параметров сетью с обученным решением о сборке | 11,87 |

Полный вариант ускорил расчёт в **3,34 раза** относительно исходной ADDA и в **3,31 раза** относительно обычного BiCGStab из сборки эксперимента. Исходную ADDA измеряли отдельной серией из 36 запусков. При одинаковом решении о сборке постоянное ядро оказалось на 0,13 с быстрее сети. Для контроля с постоянным ядром решение о сборке вычислялось до запуска таймера. В полном варианте работа модели входит в измерение. В этих условиях основной выигрыш дали параметры NPW и выбор задач, на которых стоит строить ядро. При показателе 2,15 модель пропустила построение во всех четырёх случаях. При 3,0 и 3,2 она включила его во всех восьми случаях.

Все 12 задач достигли рабочего допуска 10⁻⁵ по пересчитанной невязке. Максимальное относительное расхождение внутреннего поля полного варианта с эталоном при допуске 10⁻⁹ составило 1,73·10⁻⁴. Порог проверки поля равен 2·10⁻³. ### Сборка и запуск

Команды выполняются из каталога этой инструкции. Для последовательной сборки нужны GCC, GFortran, GNU Make и FFTW3 с заголовочными файлами.

```bash
make -C native/src seq -j4 OPTIONS=NO_GITHASH
ADDA_NPW_HEX_AUTO=1 ADDA_NPW_TIME_GATE=1 native/src/seq/adda \
  -grid 22 -shape prism 6 1.1 -m 3 0 -dpl 30 -int fcd -pol fcd \
  -iter bicgstab -precond_npw .05 hann -precond_npw_match -eps 5 -recalc_resid
```

В строке `Hex NPW action` значение `-1` означает, что предобуславливатель отключён. Остальные индексы соответствуют массиву `ACTIONS` в `experiment.py`. Вне диапазона калибровки программа применяет аналитические параметры из командной строки. Временная модель откалибрована для одного процесса на CPU. Обучающие сетки — 18 и 24, диапазон показателей преломления — от 1,75 до 3,25. Независимый тест охватывает указанные выше значения при стандартной ориентации.

### Воспроизведение

Для Python-скриптов нужны NumPy и PyTorch с поддержкой `torch.load(weights_only=True)`. Исходники нативной сборки включены в каталог `native`. Чтобы повторить контроль с поставляемыми весами, после сборки выполните:

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
python3 timed/confirm.py
python3 timed/table.py
```

Скрипт заново вычисляет строгие эталонные поля и сохраняет отдельные повторы в `timed/run/test`. В этом каталоге можно продолжить прерванный расчёт с теми же весами и бинарным файлом. Предварительная проверка без решения о сборке включает восемь других сочетаний сетки и материала и четыре повтора. [Результаты предварительной проверки](benchmarks/selector/aggregate.json)

Чтобы заново получить коэффициенты по 180 обучающим замерам ядра и 80 замерам полных времён, выполните:

```bash
python3 restore_measurements.py
python3 learn.py
python3 timed/gate.py
make -C native/src seq -j4 OPTIONS=NO_GITHASH
```

Для нового сбора меток в чистом рабочем каталоге используйте `python3 experiment.py` вместо восстановления. После `learn.py` пересоберите решатель перед запуском `timed/gate.py`, чтобы замерить время с новыми весами. [Архив обучающих замеров](benchmarks/training.json)

Для независимой проверки использована чистая ADDA ревизии `8f550a7786bd4cff5abf3cb2f2180690a08e1157`, собранная командой `make -C src seq -j4 OPTIONS=NO_GITHASH`. После `timed/confirm.py` сравнение можно повторить командой:

```bash
python3 timed/upstream_check.py /path/to/stock/src/seq/adda \
  --source-commit 8f550a7786bd4cff5abf3cb2f2180690a08e1157
```
